Questions people ask

Do I need to know how to code?

No. Start with the Intro in the editor above and change the words. You will pick up HTML and CSS by editing things and seeing what changes.

Is GitHub Pages really free?

Yes, for public repositories on a free account. Sites have size and traffic limits, but a school project or portfolio is far below them.

My page shows 404. What now?

Check that the file is named exactly index.html in lowercase, that it is in the main folder, and that Pages is turned on under Settings. Then wait a couple of minutes and refresh.

How do I change my site later?

Open index.html in your repository, click the pencil icon, edit, and commit. GitHub rebuilds the site automatically.

Can I use my own domain name?

Yes. Pages supports custom domains in the same Settings page, though you pay a domain seller for the name itself.
